# Telegram Mini App: продажа приватных чатов и каналов

Готовый мини-проект, который можно запустить локально и подключить к Telegram-боту как Web App.

## Что уже сделано
- Каталог тарифов (чат, канал, пакет).
- Форма заявки (имя, username, тариф).
- Backend API:
  - `GET /api/products` — список тарифов.
  - `POST /api/order` — отправка заявки.
- Интеграция с Telegram Web App SDK (`telegram-web-app.js`).

## Как запустить
1. Установи Node.js (версия 18+).
2. В папке проекта выполни:
   ```bash
   npm install
   npm start
   ```
3. Открой в браузере: `http://localhost:3000`

## Как подключить в Telegram
1. Создай бота через `@BotFather`.
2. Открой `Bot Settings` → `Menu Button` → укажи URL твоего приложения (должен быть HTTPS).
3. Запусти бота и нажми кнопку меню — откроется Mini App.

## Что заменить под себя
- В `server.js` поменяй массив `products` на свои тарифы.
- Для картинок карточек у каждого товара меняй поле `imageUrl` (ссылка на обложку).
- В `public/app.js` замени ссылку менеджера:
  - сейчас: `https://t.me/durov`
  - поставь свой username или ссылку на менеджера.

## Важно
Сейчас `POST /api/order` просто валидирует и возвращает успешный ответ.
Для боевого режима обычно добавляют:
- сохранение заявок в БД,
- оплату (например Telegram Stars / external payment),
- выдачу доступа автоматически после оплаты.
